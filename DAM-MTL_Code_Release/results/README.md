# Results

This directory contains the fold-level regression results and the per-monkey summary reported in the manuscript. Each fold-level file contains ten-seed outputs; `summary.csv` reports the mean and standard deviation after averaging over seeds within each target day.

Reported average correlation coefficients:

| Monkey | LODO | Forward chaining |
|---|---:|---:|
| I | 0.7508 +/- 0.0738 | 0.7467 +/- 0.0725 |
| L | 0.5516 +/- 0.0891 | 0.6058 +/- 0.0566 |

The CSV files include CC, velocity RMSE, R2, and velocity MAE.
